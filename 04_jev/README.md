# 04_jev: Jev (jev-1.13) Model Evaluation

本ディレクトリは、TypeSafe の System One モデル（`jev-1.13`）を用いた意図分類（Intent Classification）の評価および推論パイプラインを実装しています。

## 概要

`jev-1.13` の `Choice` プリミティブを使用し、全12クラスの意図分類に対して排他的かつ対照的な `criteria`（`what`, `not_for`, `examples`）を定義して確率分布を取得します。

### 信頼性と評価整合性の設計（指数バックオフ & Fail-Fast）
評価ベンチマークにおける測定値（Accuracy, Macro F1, ROC-AUC, レイテンシ）の歪曲や偽データの混入を防ぐため、以下の設計を採用しています：
- **指数バックオフ＋ジッター付きリトライ**: ネットワークの揺らぎやレートリミットに対して最大5回試行（1s, 2s, 4s, 8s, 16s + jitter）で自動再試行します。
- **Fail-Fast 原則**: リトライ上限を超えたエラーやレスポンス属性の欠損・不正に対しては、適当なフォールバック値を捏造せず、即座に例外を送出してプロセスを停止させます。
- **正当なサンプルの安全なキャッシュ**: 正常に推論が成功したサンプルのみを `tmp/` に永続化するため、異常停止時もAPIの復旧後に直前の成功地点からクリーンに再開（リジューム）可能です。

## 実際の実行実績・経過（tmpディレクトリの記録分析）

`04_jev/tmp/` に永続化された全 3,447 件の推論キャッシュファイル（`sample_*.json`）の実データを解析した、実際の実行状況・経過・挙動の記録です。

### 1. 実行全体の概要とスループット
- **実行日時**: 2026年9月20日 15:08:27 〜 15:11:40
- **総所要時間**: **193.38 秒（約 3 分 13 秒）**
- **処理サンプル数**: **3,447 件**（インデックス `0` 〜 `3446`、欠損・重複なしで完全完走）
- **実効スループット**: **約 17.83 samples/sec（毎分約 1,070 件）**

### 2. 並行処理と実行の経過
- **非同期完了順の永続化**:
  `tmp/` 内の各ファイル生成時刻（mtime）を確認すると、インデックス順（0, 1, 2...）ではなく、10本の並行ワーカースレッドでレスポンスが返ってきた順にリアルタイム保存されていました（例: `sample_1567.json` の後に `sample_1561.json` が完了）。
- **ノンストップの安定実行**:
  サンプルの完了間隔（前のサンプル保存から次のサンプル保存までの経過時間）の最大ギャップはわずか **1.73 秒** であり、プロセスの異常停止、クラッシュ、再起動などを一度も挟むことなく、単一セッションで 3,447 サンプルすべてを一気に完走しました。

### 3. レイテンシの推移と分布
各サンプルの `latency_ms` の実測値分布は以下の通りです：
- **最小レイテンシ**: 441.2 ms
- **中央値 (p50)**: 528.0 ms
- **平均レイテンシ**: 560.2 ms
- **90パーセンタイル (p90)**: 599.3 ms
- **99パーセンタイル (p99)**: 881.8 ms
- **最大レイテンシ**: 10,687.1 ms（約 10.7 秒）

全体の 99% のリクエストが 881 ms 以内に完了しており、大部分の推論が 500ms 前後という極めて高速かつ一定のリズムで処理されていました。

### 4. 実行中の一時的スパイクと自動復旧（リトライの痕跡）
- 全 3,447 件中、3秒を超過したサンプルは **10 件** のみ存在しました。
- この 10 件（`idx: 1561, 1562, 1565, 1569, 1570, 1571, 1572, 1573, 1574, 1575`）はすべて **15:09:52 〜 15:09:55（実行開始から約85秒後、進捗約45%地点）** に集中して発生していました。
- 並行稼働していた 10 スレッドが一時的なレートリミットまたは API サーバーの遅延に直面した際、指数バックオフ（1s, 2s, 4s）によるリトライが自律的に稼働し、3.8 秒〜10.7 秒かけてすべて成功に到達して復旧しました。Fail-Fast によるプロセス中断を引き起こすことなく、全件無事に回収されました。

### 5. モデル出力の確信度（confidence）プロファイル
- **平均確信度**: 0.95（中央値: 1.00）
- **最小確信度**: 0.27
- 確信度 0.50 未満のサンプルはわずか **55 件（約 1.6%）** にとどまり、3,447 件中 98% 以上のデータに対して高い確信度で明瞭な確率分布を出力して推論を完了しました。

### 6. 評価成果物の生成
全 3,447 件の個別キャッシュが `tmp/` に揃った後、即座にこれらが統合され、`output/predictions.csv` および `output/metrics.json` が生成されました：
- **Macro ROC-AUC**: **0.9708**
- **平均レイテンシ**: **560.2 ms**

## 実行方法

### 1. 動作確認（スモークテスト）
先頭10サンプルのみを対象に、API呼び出しやスクリプトの動作を確認します（成果物ファイルは保存されません）。
```bash
uv run python 04_jev/script/evaluate.py --smoke
```

### 2. 本番推論・評価の実行
全サンプルに対して並行推論（`max_workers=10`）を行い、中間キャッシュ（`tmp/`）を活用したレジューム機能付きで実行します。
```bash
uv run python 04_jev/script/evaluate.py
```

### 3. 単体テストの実行
```bash
uv run pytest 04_jev/tests/
```

### 4. 品質・型チェック
```bash
uv run ruff check 04_jev/
uv run ruff format --check 04_jev/
uv run mypy 04_jev/script/evaluate.py 04_jev/tests/test_jev.py
```
